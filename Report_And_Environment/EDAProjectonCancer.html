Introduction

We all know someone close to us who has been affected by cancer throughout their lifetime. And in recent times, the cancer statistics that we come across have been extremely alarming. For instance, according to the National Cancer Institute, over 40% of Americans will be diagnosed with cancer during their lifetimes (USAFacts). Recognizing the significance that this condition will impose on the health and well being for the coming generations, we decided to gain a deeper understanding of it. Using Emory’s Library resources we decided to leverage two datasets about Cancer Incidence and Mortality that were originally published in the US Cancer Statistics Database.

The datasets primarily consist of cancer statistics across different states in the US from the year 1999 to 2021. After an initial look at the datasets, we hope to explore any possible trends in incidence and mortality of cancer over the years, and whether certain years are more prevalent in any of the US states. We would also be interested in exploring any correlations between the mortalities and incidences across all states and years. Ultimately, as we explore the dataset, our aim is to uncover any trends and correlations of the variables mentioned above in an attempt to grow our understanding of where cancer research efforts and funding should be focused in the coming years.

Data Collection

As mentioned above, the two combined datasets from the US Cancer Statistics Database allowed us to create a massive dataset with the following columns - State, Cancer Type, Sex, Year, Incidence Count and Mortality Count. We soon realized that it would not be possible to directly compare the incidence counts and mortality counts across all the states. Since each state has a very different population count, bigger states like California and Texas would be overrepresented in our analysis. To control for the differences in population, we wanted to calculate and analyze incidence and mortality rates as a percentage of the states’ total population. In order to do this, we had to manually integrate 52 datasets using the excel files from the US Census Bureau that included population statistics based on sex for the years 2000 to 2010 (US Census Bureau). This manual integration was completed by extracting the values from each of the sheets and placing then into a new excel sheet titled “masterpopulationbystatesbysex.csv”. This process was true for every year except 1999 which did not have population data that was split based on sex, which is why it was excluded. For the years 2011-19 and 2020-21, there were datasets that included all the necessary data for each of the states in a single dataset, respectively, which was directly imported (US Census Bureau). The final step was to merge all the different dataframes into one, giving us a master dataset that included the following columns - State, Year, Incidence, Mortality and Population.

After downloading and creating the files explained above, we loaded in the data as well the necessary packages to begin manipulating the data into a format that will reflect our exploratory analysis. The only package that we will be using for this analysis is tidyverse.

Summary of Data Structures:

Incidence - This dataset provides the cancer incidence counts for specified populations. Each variable represents a specific population based on the type of cancer, the year, the sex, and incidence. Each observation in the dataset then signifies the count of incidences for that specified population.

Mortality - Similarly, this dataset provides the cancer mortality counts for specified populations. Just like the Incidence dataset, each variable represents a specific population based on the type of cancer, the year, the sex, and mortality. Each observation in the dataset signifies the count of mortalities for that specified population.

populationdata19992010 - The variables of interest that are present in this dataset are Male Popultion, Female population, Year and State. Both the Population variables of interest each denote the male and female population respectively for each state in a given year.

populationdata20112019 - The variables of interest in this dataset are Name which denotes the name of the state, Sex which denotes the sex of the population, and POPEST{year}_CIV where year =[2011,2019] which denotes the year for that population.

populationdata20202023 - Similar to the populationdata20112019 dataset the variables of interest are the NAME, SEX and POPEST{year}_CIV where year =[2020,2023], which all share the same description as the variables found in the populationdata20112019.

Merging Importance: We must know and keep into account the formatting of the columns and the variable values themselves in order to ensure a seamless merging process.

Important Note on Population Data from US Census: For all of the population data obtained from the US Census Bureau, we use their estimated population counts which the Bureau derived using a formula that takes into account a population base, migration trends, and past growth trends for a given state.

Data Manipulation

We must change the current data structures of the tables, in order for them to be merged and analyzed together. This will provide a more fruitful exploratory analysis as opposed to just parsing the summary statics of few variable from differing datasets that have no correlation to each other.

Incidence and Mortality tables

Given the current data structure of the Incidence and Mortality tables, we will not be able to perform any meaningful analysis as the variables are in a format that doesn’t separate the cancer type, the year, the sex, or incidence/mortality. Therefore to get more detailed variables, we must break it down into separate variables like CancerType, Sex, MortalityCount/IncidenceCount, and Year using the pivot longer.

Another note is that some of the cancer types, like urinary cancer, have a comma in their name, which would cause problems in the presented method of separation. Therefore, the comma was removed.

#Now we must convert our datasets into a long format rather than a wide format before performing any data analysis and also change the name of the urinary cancer to make the data easier to handle.

IncidenceLong <- Incidence %>% 
  pivot_longer(., cols = -State,names_to = "CancerTypeIncidenceSexYear", values_to = "IncidenceCount") %>% 
  mutate(CancerTypeIncidenceSexYear= sub("^Urinary Bladder, invasive and in situ,","Urinary Bladder invasive and in situ,", CancerTypeIncidenceSexYear)) %>% 
  separate(CancerTypeIncidenceSexYear, into = c("CancerType", "Incidence","Sex","Year"),sep=",")

MortalityLong <- Mortality %>%

Variable Creation

After merging and collapsing the data to get the overallMergedDatawithPopulation table, we created two new columns for incidence rate (total incidents in a given state / population in a given state) and mortality rate (total mortalities in a given state / population in a given state) to control for population sizes across states in the dataset.

#From the overallMergedDatawithPopulation, we created new variables that showed the incidence rate and mortality rate. We also filtered for the population not equal to 0.

OverallData<-overallMergedDatawithPopulation %>%
